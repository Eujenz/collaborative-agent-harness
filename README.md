# collaborative-agent-harness

A lightweight workflow scaffold for working with coding agents across long-running sessions.

## What it helps with

- checkpointing and session handoff
- Git hygiene during agent-assisted development
- workspace organization
- UTF-8-safe PowerShell usage
- repeatable collaboration patterns between human and agent
